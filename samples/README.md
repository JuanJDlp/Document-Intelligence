# Synthetic receipt fixtures

All documents are artificial and contain no real customer data. Run make samples to regenerate document inputs. The sample merchant SYNTHETIC MARKET and invoice INV-001 are test data. The base NIT 900123456 has check digit 8 using right-to-left weights 3,7,13,17,19,23,29,37,41; it does not identify a verified business.

Golden expectations and fake OCR recordings are independently authored; they are not generated by the extraction engine. Real Tesseract is checked separately with make test-ocr.
